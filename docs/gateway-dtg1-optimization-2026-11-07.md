## 已准备的改动

- 路由电机反馈直接进入最新完整记录缓存，消除同一反馈额外入队、排空和重建；PDO owner 不再重复聚合 CAN。
- SBUS 保留单个待确认块，去掉中间八块队列和重复编码；20 ms 保护不变。
- 有界采集处理后 yield 并等待事件，取消固定 100 µs 休眠。最新本地候选进一步在成功 DMA 回调发布完整 IMU 页、在有界 UART ingress 直接解析发布 HI91，取消 HI91 线程和消息复制；该进一步改动未实测。
- CAN 消息 RAM 准备阶段允许外部中断，最后 TXBAR 请求前在驱动锁内检查状态、保护、时效和序号。模拟 Stop 在准备中到达、旧命令过期/被取代、拒绝后 token 恢复的合同测试通过。正常协议签名仍为 DTG1。
- Arm 状态应答保持到首批有效电机命令，避免短脉冲应答被两次主站读取错过。

更正：源码的接收忙等待只适用于特定 SoC 条件分支；实际 HPM5E31 预处理结果没有 CAN_SOC_TX_RX_BUFFER_ACCESS_WORKAROUND。它不能被归因为本板长尾。

IRQ 顺序、全局 -O2、固定左侧约 200 µs 相位，以及仅将下一次 DMA 启动移到发布之后的方案未证明稳定收益，均已撤回。当前默认仍为 -Os 和原 IRQ 优先级。旧 410 B ESC 异步 DMA 实验没有改善端到端延迟，本轮没有在缺乏新预算证据时重新引入该机制。

## 来源证据与边界

CAN-only 诊断测得左轮总线 SOF 最大约 1984 µs、MCU 回调最大 2000 µs、主站最大 2000.02 µs。另一轮测到左轮 SOF 最大 2032 µs。硬件计数器粒度 16 µs（1 Mbps 下 16 个标称位时间），不能把这些数值当作纳秒精度的线缆测量。它们表明左轮源间隔本身已几乎没有 2 ms 预算余量，不能仅以主站到达长尾认定是 EtherCAT。

B 关节 ID 0x011、0x010 在约 30 s 内各有约 60000 个源间隔，约 2 kHz；D 关节约 1 kHz。这一上报行为及其仲裁占用需要核实，不能仅依据原先“问答机制”假设估算总线负载。

IMU 诊断轮次 DRDY 最大 1393 µs、DMA 完成最大 1325 µs，而主站最大 2000.02 µs，说明完成后交接仍存在软件优化空间。DRDY 是 GPIO 回调观察到的间隔，包含中断响应延迟，不能据此直接判定传感器物理引脚波形。新直接交接候选正是针对这段等待，效果尚未实测。

源统计只在 CONFIG_ECAT_SOURCE_ARRIVAL_STATS=y 时编译，config/labs/source-arrival.conf 为手动测量配置；默认及已构建隔离镜像均关闭该开关和 HPM_MCAN_RX_TIMING。历史原始字段 sof_to_callback_max_us 实为 SOF 至驱动计数器采样的年龄，包含帧传输时间；新工具命名为 sof_to_driver_sample_max_us。
