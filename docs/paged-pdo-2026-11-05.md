# 2026-11-05 固定 192 B 类型分页试验

上行 SM3 为 192 B，主站周期为 125 μs，全程关闭电机输出。固件逐次提交 CAN0、
UART2、CAN3、UART2、IMU，UART5 每约 5 ms 取得一个机会，诊断请求可插入。
主站每收到一页就更新对应区域。192 B 的尺寸用于在一页内携带完整的 128 B UART
流块和元数据。布局与复现条件见 [分页实验说明](../tests/probes/paged/README.md)。

| 项目 | 原 410 B 对照 | 192 B 正常轮 | 192 B 跳页轮 |
|---|---:|---:|---:|
| Active 时间 | 20 s | 20 s | 20 s |
| 右 CAN 提交年龄均值 | 294 μs | 547 μs | 547 μs |
| 左 CAN 提交年龄均值 | 279 μs | 536 μs | 537 μs |
| HI91 块提交年龄均值 | 414 μs | 526 μs | 497 μs |
| 板载 IMU 提交年龄均值 | 1007 μs | 794 μs | 783 μs |
| 状态往返均值 | 702 μs | 548 μs | 522 μs |
| HI91 严格解码错误及流不连续 | 0 / 0 | 0 / 0 | 0 / 0 |

原配置数据来自 [410 B 对照报告](compact-pdo-2026-11-05.md)。
分页跳页轮 MCU 循环平均 215 μs，ESC 写入平均 29 μs，原对照分别约 341 和
66 μs。CAN 和 HI91 年龄从 MCU 采集事件计至 ESC 提交。各类页面按 MCU 发布
轮次推进，125 μs 是主站读取周期。两个最终分页轮均正常 Stop，未触发 WKC
停机。跳页轮屏蔽了一个 UART2 页的所有重复读取，并继续接收后续页。

早期调度分别出现 UART 超时、过旧样本、流不连续及 CRC 错误。提高 UART5
配额时，原有单个 UART2 机会也被进一步稀释。最终采用两个交错的 UART2
机会，给 ACK 留出时间。两轮通过仅覆盖短时无输出台架，偶发 WKC 仍需独立定位。

已烧回实验前普通 410 B 镜像，10 s 无输出复核完成，HI91 严格解码错误为 0。
[逐轮原始记录](paged-pdo-2026-11-05.json) 保留早期失败、最终轮次及恢复复核。
