# 按设备划分的 10 B PDO 草案

首轮范围为六个电机及板载 IMU。UART 暂不映射。已确认每次交换的过程数据为固定 Rx 10 B、Tx 10 B，各自一次提交一条记录。以下是首版线格式。

| 设备 | CAN 通道 | 命令 ID | 反馈 ID |
|---|---:|---:|---:|
| 右轮 | 0 | 0x200 | 0x201 |
| 右关节 B | 0 | 0x001 | 0x011 |
| 右关节 D | 0 | 0x002 | 0x012 |
| 左轮 | 3 | 0x200 | 0x201 |
| 左关节 B | 3 | 0x000 | 0x010 |
| 左关节 D | 3 | 0x003 | 0x013 |

每条记录固定为 `类型/设备编号 1 B + 序号 1 B + 载荷 8 B`。类型值
0x10–0x15 按表格顺序绑定电机。Rx 和 Tx 各用同一组设备编号，固件按方向选择
命令或反馈 ID。单次交换可同时下发某个设备的命令和上报另一个设备的数据。

板载 IMU 保留现有 38 B 记录，按 0x20–0x24 分五片。五片共享一个样本序号，
最后一片承载 6 B，尾部 2 B 填零。发送侧应冻结同一个样本，主站检查顺序、
样本序号和超时后才交付。缺片或过期会使该样本失效。

0x30–0x34 预留给 Discover、Ready、Arm、Stop 和 Status，每条控制消息也占用
一次 10 B 交换。会话握手载荷、命令租约和停止状态机仍需接入。重复或重放命令
不得续期，Stop 需要优先，重连需要清空命令及 IMU 分片状态。首轮实板验证保持
电机输出关闭。

六个电机和五片 IMU 共占 11 次上行机会。按 125 μs 计算，完整轮转的理想下限为
1.375 ms，尚未计入控制记录、MCU 提交间隔和调度抖动。分别测量两个方向的实际
提交频率以及各设备的更新年龄。

[共用线格式](../src/common/device_pdo.hpp) 已实现定长编解码、固定 CAN 路由和
IMU 重组。[离线合约](../tests/probes/device_pdo/contracts.cpp) 已通过 ASan/UBSan，
覆盖方向、尺寸、序号回绕、重复页、缺片、超时和末片填充。SSC 和 IgH 的
10 B 物理映射及会话尚未接入。
