# 2026-11-05 PDO/ESC 耗时对照验证

后续分段计时与重复发布优化见 [主循环优化记录](bench-loop-2026-11-05.md)。

> 计时有效性补记：本轮初测未在读取前显式回写统计区的数据缓存。后续发现调试器读取 RAM 快照可能不一致，故本页历史量化结果仅作初测参考；最终分段结论以补齐缓存回写后重新采集的 [主循环优化记录](bench-loop-2026-11-05.md) 为准。

两项验证已完成。**逐字节 ESC 访问确实消耗大量时间，但优化后完整主循环仍超出 125 us，WKC 异常也仍存在。**

## 条件与统计口径

- 同一 HPM5E31、同一上位机，RxPDO 131 B / TxPDO 410 B，布局签名 0x76788646。
- 上位机 125 us、SCHED_FIFO 80、CPU3，enable_output=false；未发送电机力矩测试指令。
- 两组均开启 CONFIG_ECAT_BENCH_TIMING，每组 3 轮，每轮上限 20 s；故障发生时按现有策略退出。
- 原版驱动：长度非 4 倍数的整个 PDO 走逐字节访问。优化版：对齐 32 位主体＋1～3 个尾字节，布局不变。
- 计时用 k_cycle_get_32()，硬件计数频率 24 MHz，分辨率约 0.0417 us。
- 统计保存在 RAM，测试期间不打印统计、不读取统计，停止后通过 OpenOCD sysbus 读取。探针保持连接。
- 主循环统计从 Active 状态入口开始，包含 ISR 抢占及结束边界，不是隔离的纯 CPU 指令耗时。
- 上行映射从 APPL_InputMapping 入口计至 ESC 写入完成，包括 late CAN refresh、内存拷贝和写入；下行从 ESC 读取开始计至 APPL_OutputMapping 拷贝完成。SSC 调用这些核心步骤之前的寄存器读取等前置工作不在映射计时内，但包含在主循环计时内。
- 平均值按各轮样本数加权，最大值是本次观测最大值，并非最坏执行时间保证；计时代码自身开销未扣除。

## 稳定性观察

- 原版：一轮约 6.6 s 退出（含 SSH/启动时间），其余两轮到 20 s 上限。
- 优化版：两轮到 20 s 上限，一轮约 10.8 s 退出（含 SSH/启动时间）。
- 两组提前退出均为 operational=1、complete=0，即从站仍为 OP、主站 domain WKC 不完整。
- 20 s 上限由 timeout 发送 SIGINT，返回码 124。SIGINT 后的 master stopped 或 OP/WKC 日志属于结束过程，不计为提前失败。
- 样本时长不等且每组只有三轮，不能据此断言优化降低了 WKC 故障率；没有完成长时间稳定性验收。

## 判断

1. 410 B 逐字节写入平均约 112 us，接近 125 us；该路径确实是应优先优化的瓶颈。
2. 32 位主体＋尾字节把 ESC 读写平均耗时约减半，但优化后单主循环平均仍约 480 us，不能保证每 125 us 处理一份新的应用 PDO。
3. EtherCAT 硬件帧交换与应用更新速率不同；循环超预算并不单独证明每次 WKC 异常的根因。此次优化未消除异常。
4. 主循环还包含 Poll/SSC/IO 服务、反馈编码、传感器与热控；下一步应分段测量剩余耗时和重复发布次数，再评估缩减影像、减少重复工作或调整更新周期。

## 修改和复现

- 驱动修改位于 hpm_support/drivers/ethercat/esc_hpmicro.c 与 Kconfig.hpmicro。寄存器访问路径不变，不跨越请求范围、不补齐越界读写。
- ASan/UBSan 临时检查覆盖长度 8～1025 B、CPU 缓冲偏移 0～3，读写内容一致且未发现越界；并检查 PDRAM 边界/非对齐地址回退。
- 计时默认关闭；启用 CONFIG_ECAT_BENCH_TIMING=y 后构建，统计只针对本次生产 SM 地址 0x1100/0x1d00。
- 主站停止后，以 历史计时读取工具（正式化时已撤下） 读取；需要匹配当前固件的 ELF、GNU nm，以及 OpenOCD TCL 端口 6666。
- 原始六轮日志和计数见 [JSON 数据](bench-timing-2026-11-05.json)，读取工具见 已撤下的历史调试工具。
